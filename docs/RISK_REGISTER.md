## Highest-priority integration risks

1. **Secret leakage (R13):** probable live credentials already exist in legacy files and one plaintext note.
2. **Incomplete/brittle source acquisition (R1–R5, R21–R22):** EnglishJobs has no full-detail implementation and both collectors lack production-grade resilience.
3. **False duplicate decisions (R6–R7):** cross-source merging affects notification, CV selection, and application status, so provenance must remain reversible.
4. **Scoring/AI truthfulness (R9–R12):** five score concepts and duplicated candidate facts can produce misleading rankings or CV claims.
5. **Persistence/idempotency (R15–R18, R23–R24, R26):** migrations, concurrent writes, run recovery, and notification/status uniqueness are correctness boundaries.

## Release gates

- No live integration run until discovered credentials are rotated and root secret loading/redaction tests pass.
- No source enabled until fixture contracts, bounded pagination, and partial-failure reporting pass.
- No cross-source notification until the duplicate gold dataset and cluster idempotency tests pass.
- No AI-polished artifact presented as final without a retained rule-based artifact and validation result.
- No schema migration or legacy import without a restorable backup and reconciliation report.
